# Guindonville — Val-David, 2003

Reconstitution du site web des locataires de Guindonville (guindonville.ca.tc, 2003) à partir des archives de la Wayback Machine, avec les textes, les photos, la revue de presse et des extraits du film tourné sur place.

Site statique bâti avec [Astro](https://astro.build). Déploiement sur Cloudflare Pages.

```
npm install
npm run dev      # http://localhost:4321
npm run build    # génère dist/
```

Paramètres Cloudflare Pages : commande de build `npm run build`, dossier de sortie `dist`.
